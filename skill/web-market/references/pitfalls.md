# 실제로 밟은 함정

1. **클래스 이름 충돌** — `.btn.line`(외곽선 버튼)과 드로어의 `.line`(장바구니 줄, grid)이 겹쳐 버튼이 3칸 그리드가 됐다. `.btn.sec`↔`.sec`(섹션 패딩)도 같은 사고. 짧은 공용 이름을 수식 클래스로 쓰지 않는다.
2. **목록 항목에 grid 금지** — `li`/줄 요소를 grid로 두면 좁은 폭에서 글자가 세로로 한 자씩 쌓인다. 줄은 flex + `min-width:0`.
3. **입력칸 넘침** — `input`·`select`는 기본 최소 폭이 있어 2열 폼이 320px에서 넘친다. `.f`와 입력 모두 `min-width:0; width:100%`, 480px 아래는 1열.
4. **칩 줄바꿈** — 옵션 칩은 `white-space:nowrap`. 가로 스크롤 칩 줄은 `overflow-x:auto` + 스크롤바 숨김 + 부모 `min-width:0`.
5. **스티키 툴바 겹침** — 목록 툴바 `top`은 헤더 높이와 같게(60px). 공지 띠는 스크롤되므로 계산에서 뺀다.
6. **localStorage 예외** — 사생활 모드·차단 설정에서 접근 자체가 throw → 읽기·쓰기 모두 try/catch.
7. **옵션 문자열에 따옴표** — `onclick="pick(this,'크기','24cm')"`에 작은따옴표가 들어가면 깨진다. 옵션 라벨에 따옴표를 쓰지 않거나 `esc()`로 감싼다.
8. **호버 전용 버튼** — "바로 담기"는 `@media (hover:none)`에서 숨긴다(터치에선 눌러지지 않고 가려만 짐).
9. **검증 스크린샷 글꼴** — 웹폰트 로딩 전에 찍으면 대체 글꼴 화면을 보고 판단하게 된다. `document.fonts.ready` 대기.
10. **리빌 요소가 안 보임** — 풀페이지 캡처는 IntersectionObserver가 안 걸린다. 캡처 전에 `.rv`에 `in`을 강제로 붙인다(verify.mjs가 함).
11. **사진 워터마크 흔적** — delogo는 번진 자국이 남는다. 상품 사진은 크롭이 낫다.
12. **라우트 이동 후 스크롤** — 해시 라우팅은 스크롤 위치를 유지한다. `route()` 끝에서 `scrollTo(0,0)`, 섹션 링크(`#/#story`)만 예외.
