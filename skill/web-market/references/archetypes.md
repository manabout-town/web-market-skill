# 품목별 설계표

새 몰은 이 표에서 고르거나 같은 방식으로 새 줄을 만든다. **심장 기능 = 그 품목을 살 때만 생기는 고민을 풀어주는 기능.**

## 제작 완료 (코드로 확인 가능)

### 결 GYEOL — 수제 도자기 · 에디토리얼
- 색: 종이 #F4F1EA, 잉크 투명도 4단, 강조 녹 #9A4A2A. 글꼴: Noto Serif KR + Cormorant(영문 이탤릭) + IBM Plex Sans KR. radius 2px.
- 홈: 잡지 지면 — 좌 제목·우 큰 사진, 비대칭 12칸 "이번 호의 그릇" + 인용문, 작업실 이야기(2단 칼럼·드롭캡·수치 3개), 관리법 4칸, 소식 받기.
- 심장 기능: 한정 수량 태그, 품절 = "다음 가마 대기 · 입고 시점", 한 장의 사진을 세 가지 프레이밍(object-position + scale)으로 썸네일화(사진 수 절약), 수작업 편차 안내 아코디언.
- 결제 동의 문구에 "수작업 그릇의 특성(색·크기 편차)" 포함.

### KEYFORGE — 커스텀 기계식 키보드 · 다크모드
- 색: 어두운 배경 + 오렌지 1색. 데이터: `SWITCHES`(축별 소리 성격), `ROWS`(키 배열), `HOUSING_TINT`(하우징 색 옵션 → 보드 색 변경).
- 첫 화면: 키캡을 눌러 브랜드명이 켜지는 인트로 + 커서·실제 키 입력에 반응하는 입체 키보드 히어로(`signature-hero` 스킬 레퍼런스 1호).
- 심장 기능: 스위치 옵션 옆 "소리 듣기" — WebAudio 합성 타건음(첫 입력 전엔 재생 안 함, 끄기 버튼).

### SOOM 숨 — 비건 스킨케어 · 미니멀리즘
- 데이터 추가 필드: `size rating reviews for lead key inci how restock`.
- 심장 기능 3개가 한 흐름: ① 루틴 찾기(피부 3종 × 아침/저녁 → `ROUTINE[skin][time]` 3제품) → ② "루틴 한 번에 담기" = 3종 세트 10% 할인 → ③ 상세의 구매 방식 라디오 "한 번 구매 / 정기배송 6주마다 −15%" (`PLAN` 배열, 옵션처럼 장바구니 키에 포함).
- 전성분 전체 표기, 사용법 3단계, 정기배송이 있으면 결제 동의 문구에 자동결제·해지 안내를 덧붙인다.

## 새 품목 후보

| 품목 | 스타일 | 심장 기능 | 첫 화면 |
|---|---|---|---|
| 원두·드립백 | 에디토리얼 또는 미니멀 | 맛 지도(산미×바디 2축)에서 고르기, 분쇄도 옵션, 정기배송 주기 | 원두 붓기(드래그) |
| 와인·전통주 | 다크모드 | 음식 궁합 필터, 성인 인증 게이트(데모), 6병 박스 할인 | 잔에 따르기 |
| 꽃·식물 | 그라디언트 메시 | 받는 날짜 달력(당일 마감 시각), 메시지 카드 문구, 크기 비교(사람 실루엣) | 포장지 펼치기 |
| 반려동물 용품 | 벤토 그리드 | 몸무게·나이로 사료량 계산 → 정기배송 주기 자동 제안 | 공 던지기 |
| 가구·조명 | 미니멀 | 방 치수 입력 → 들어가는지 표시, 색상 스와치로 사진 교체 | 스위치 켜면 방이 밝아짐 |
| 향수·캔들 | 그라디언트 메시 | 향 노트 피라미드, 시향 샘플 3종 담기(본품 구매 시 차감) | 향이 번지는 메시 |
| 문구·굿즈 | 레트로/Y2K | 각인 문구 미리보기(글자 수 제한), 스티커 뽑기 증정 | 스티커 떼기 |
| 의류 | 브루탈리즘 | 키·몸무게 → 사이즈 추천, 모델 착용 정보, 룩북 | 옷걸이 넘기기 |
| 산지 농산물 | 에디토리얼 | 수확 달력·예약 판매, 산지 이야기, 크기 등급 비교 | 상자 열기 |

## 한 세션에 여러 몰을 만들 때

- 스타일·심장 기능·첫 화면이 서로 다른 칸이어야 한다. 폴더당 에이전트 1명으로 나눠도 되고, 이 경우 브리프에 이 표의 한 줄과 사진 파일명 목록을 고정해서 준다.
